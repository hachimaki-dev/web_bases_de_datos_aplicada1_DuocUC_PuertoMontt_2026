Configuración paso a paso para Laboratorios Duoc UC y Docker personal

⚠️
REGLA DE ORO: Primero debes conectarte como Administrador (Admin)

Una base de datos recién instalada o reiniciada aún no tiene creado tu usuario de desarrollo. Primero debes conectarte obligatoriamente con el usuario administrador (SYS o SYSTEM) para habilitar scripts, crear a usuario_desarrollador y otorgarle permisos y cuota.

Abre el panel de Extensiones en VS Code (Ctrl+Shift+X en Windows o Cmd+Shift+X en Mac):

🗄️
Oracle Developer Tools for VS Code (SQL and PL/SQL) Extensión oficial desarrollada por Oracle Corporation (ID: oracle.oracledevtools)
Recomendada

Una vez instalada, aparecerá el ícono de la base de datos de Oracle en la barra lateral izquierda. Haz clic en el botón + (Create Connection) para configurar la primera conexión.

3

Ejecutar el Script SQL con el Administrador

Haz clic derecho en la conexión de Administrador recién conectada y selecciona "Open SQL Worksheet". Pega y ejecuta el siguiente script:

Oracle SQL Script 
-- Habilita la creación de usuarios en Oracle 12c/19c/21c/23c
ALTER SESSION SET "_ORACLE_SCRIPT"=TRUE;

-- Crear el usuario
CREATE USER usuario_desarrollador IDENTIFIED BY "123456"
DEFAULT TABLESPACE "USERS"
TEMPORARY TABLESPACE "TEMP";

-- Asignar cuota y permisos básicos
ALTER USER usuario_desarrollador QUOTA UNLIMITED ON USERS;
GRANT CREATE SESSION TO usuario_desarrollador;
GRANT "RESOURCE" TO usuario_desarrollador;
ALTER USER usuario_desarrollador DEFAULT ROLE "RESOURCE";

💡 ¿Qué hace cada sentencia de este script?

  • ALTER SESSION SET "_ORACLE_SCRIPT"=TRUE;: En bases de datos Oracle Multitenant (CDB/PDB), los usuarios normalmente exigen el prefijo C##. Esta instrucción desactiva temporalmente esa restricción para crear un usuario de desarrollo estándar.
  • CREATE USER usuario_desarrollador IDENTIFIED BY "123456" ...: Crea el usuario personal con clave 123456 y le asigna el tablespace de almacenamiento USERS y de temporales TEMP.
  • ALTER USER usuario_desarrollador QUOTA UNLIMITED ON USERS;: Le asigna cuota de almacenamiento ilimitada en el tablespace para que puedas crear tablas e insertar datos sin errores de cuota (ORA-01950).
  • GRANT CREATE SESSION ...;: Le otorga el permiso indispensable para poder autenticarse e iniciar sesión en Oracle.
  • GRANT "RESOURCE" ...;: Le otorga el rol de desarrollo que incluye privilegios para crear tablas, secuencias, vistas y triggers.

¿Cómo ejecutarlo en VS Code? Selecciona todo el código con Ctrl+A (o Cmd+A) y presiona la tecla F5 o el ícono de "Execute as Script" (la página con play/engranaje en la barra superior del editor).

🛠️ Errores Frecuentes y Cómo Solucionarlos

ORA-28009: connection as SYS should be as SYSDBA or SYSOPER

Ocurre al conectar con SYS en Duoc UC sin cambiar el Role. Cámbialo de Default a SYSDBA.

ORA-12505 / ORA-12514: listener does not know SID/Service

Revisa el botón de radio de conexión: en Duoc UC debe ser SID: ORCL, mientras que en Docker debe ser Service Name: FREEPDB1.

ORA-01017: invalid username/password; logon denied

Revisa que la clave sea exactamente 123456 y que no tengas las mayúsculas activadas (Bloq Mayús / Caps Lock).

ORA-01045: user lacks CREATE SESSION privilege

Faltó ejecutar GRANT CREATE SESSION TO usuario_desarrollador; desde el usuario Administrador.
